# 🧠 Квиз-бот для Telegram

Бот задаёт 10 вопросов на тему Python, сохраняет последний результат каждого игрока и показывает статистику.

## Команды бота

- `/start` – приветствие и кнопка «Начать игру»
- `/quiz` или кнопка **Начать игру** – запуск нового квиза
- `/stats` – показать ваш последний результат (количество правильных ответов)
